# Data Science Programming Languages — 2026

М.А. Гейне ([geine@bmstu.ru](mailto:geine@bmstu.ru))

Курс «Языки программирования для анализа данных»: Python, преобразования данных,
функции и объекты, библиотеки анализа, модель исполнения и проверка результата.

## Среда

Python **3.14**, зависимости — только через **uv**.

```sh
uv sync --locked
uv run --locked jupyter notebook
```

Команды выполняются из корня репозитория. uv установит Python и создаст `.venv`.
[Установка и выбор ядра в VS Code](dependencies/README.md).

## Семинары

1. [Основы программирования на Python](notebooks/C0_PyBasics.ipynb) — значения,
   коллекции, функции, итерация, объекты и эффекты.
2. [Числа, строки и алгоритм Луна](notebooks/C1_luhn.ipynb) — от пошагового
   алгоритма к композиции преобразований и проверкам.
3. [Функции в Python](notebooks/C2_functions.ipynb) — S3: параметры, функции
   высшего порядка, декораторы и декомпозиция задач. Основной маршрут —
   «Основы работы с функциями» и «Трекер расходов»; «Ханойская башня» —
   дополнительные примеры рекурсии, состояния и пошагового улучшения решения.

4. [Классы и объекты в Python](notebooks/C2_classes.ipynb) — S4: создание объектов,
   инкапсуляция, наследование, полиморфизм и специальные методы. Основной маршрут —
   «Основы работы с классами»; банковская система — дополнительный составной пример.

Тетради — законченные демонстрации и конспект. Основной маршрут указан в тетрадях
или в описании выше, дополнительные примеры остаются справочником.
Для проверки воспроизводимости: **Restart Kernel → Run All**.
